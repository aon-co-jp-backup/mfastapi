**English**: Win32 wheels are confirmed shipped (the stale "not yet" was corrected). The standalone Rust server (`rust/mfastapi-server`) is CI-built for Linux/Windows/macOS on x64 and ARM64, smoke-tested (it starts and answers) and attached to the Release (`server` job in `.github/workflows/wheels.yml`, from v0.2.2). **Update (2026-11-16)**: the Rust server now handles GET/HEAD/POST/PUT/PATCH/DELETE and JSON bodies (`Route.method`/`Route.body`, `Args::json()`). A missing body gives 422 `missing`, invalid JSON 422 `json_invalid`, a path match with the wrong method 405 + `Allow`, bodies over 1 MB 413; OpenAPI lists per-method operations and `requestBody`. The CI smoke test now covers POST/405/422. **Open**: whether to retire the Mojo server, PyPI publication (needs the owner's account), real Android/iOS/BSD/TV devices.
